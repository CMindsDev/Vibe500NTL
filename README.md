# Project Hollow (500 Startups Explorer)

Este proyecto es una plataforma interactiva construida con **Next.js** y **Framer Motion**, diseñada para explorar y gestionar conexiones de startups. 

## Características principales

- **Experiencia Inmersiva:** Uso extensivo de animaciones 3D, layouts tipo "Folio" y transiciones fluidas.
- **Glassmorphism y UI Premium:** Tarjetas responsivas con efectos translúcidos y sombras dinámicas.
- **Ambient Glow Dinámico:** Los fondos de pantalla reaccionan en tiempo real al contenido (acentos de color) que está siendo visualizado.

## Tecnologías

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [Framer Motion](https://www.framer.com/motion/)
- CSS Modules / Vanilla CSS personalizado

## Inicio Rápido

1. Clona el repositorio:
   ```bash
   git clone https://github.com/KillerSpartan/project-hollow.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.
